# web-backend

## Requirements

- [nodejs & npm](https://nodejs.org/en/), see `engines` in [`package.json`](./package.json) for versions

## Getting started
### Configuration
* Set up the server application by copying the `example.env` file to a `.env` file.
  This standard configuration works with the default dev environment configuration of the provided `docker-compose.yml` file.
* Run the migration script using `npm run migrate` to set up the database before running the server.
* Configure the minio client with an alias (use `mc alias set raftmodding-local http://localhost:9000 minio minio-password` to configure `raftmodding-local` with the default credentials of the docker compose setup) and run the setup script:
  ```sh
  # General usage:
  ./server/resources/bucket/setup-minio.sh "<mc-alias>" "<password-for-raftmodding-web>"
  # Defaults for dev container:
  ./server/resources/bucket/setup-minio.sh raftmodding-local web-backend-password
  ```

### Development scripts

* Run dev server:
  ```sh
  npm run dev
  ```
* Build prod server:
  ```sh
  npm run build
  ```
* Apply code style:
  ```shell
  npm run format
  ```

## Routes & Spec
Routes (routes.ts) & Specs (swagger.json) are generated by tsoa.
tsoa is configured in [`tsoa.json`](./tsoa.json).
